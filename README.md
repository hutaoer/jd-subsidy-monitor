# 京东国补监控插件

一个 Chrome 插件，自动监控京东商品详情页有没有「国补」。检测到国补时，电脑弹系统通知，同时通过 Server酱 推送到微信，帮你第一时间去领券下单。

## 功能

- 监控所有 `item.jd.com` 商品详情页，每 20~30 分钟随机自动刷新页面，保证检测的始终是最新状态
- 通过正则匹配「领后减¥xxx」文案判断国补状态，并提取减免金额（兼容全角/半角 ¥）
- 只在国补**从无到有**的那一刻提醒一次，国补消失后再出现才会再次提醒，不重复打扰
- 检测状态存在 chrome.storage 里，跨页面刷新、按商品独立去重
- 检测到国补时双通道通知：
  - 电脑端：Chrome 系统通知，带商品名和减免金额
  - 手机端：Server酱 微信推送，点开消息可直接打开商品页

## 文件结构

```
├── manifest.json   # 插件配置（MV3）
├── content.js      # 注入商品页的检测脚本，每 20~30 分钟随机刷新检测
├── background.js   # 后台脚本，负责弹系统通知和 Server酱 微信推送
├── standalone.js   # 控制台独立版，直接粘贴到控制台即可运行（支持无痕模式）
├── icon.png        # 通知图标
├── article.md      # 项目介绍文章
└── prd.md          # 原始需求
```

## 安装

1. 打开 Chrome，地址栏输入 `chrome://extensions`
2. 打开右上角的「开发者模式」
3. 点击「加载已解压的扩展程序」，选择本项目文件夹
4. **刷新**你要监控的京东商品页（关键：装插件之前就打开的页面不会被注入脚本，必须刷新）

## 配置微信推送（可选）

不配置也能用，电脑端通知不受影响。

1. 打开 [sct.ftqq.com](https://sct.ftqq.com/)，微信扫码登录
2. 复制页面上的 SendKey
3. 粘贴到 [background.js](background.js) 第 8 行：

```js
const SERVERCHAN_SENDKEY = '你的SendKey';
```

4. 在 `chrome://extensions` 里点击插件卡片的「重新加载」
5. 按网站引导关注微信「方糖」服务号，消息从这里推送

> 免费版每天最多推 5 条。插件只在国补状态变化时推一条，一般够用；超出额度时电脑端通知照常工作。

## 控制台独立版（支持无痕模式）

不想装扩展，或者在无痕模式下使用，可以用独立版脚本，直接粘贴到控制台运行。

1. 打开京东商品详情页（`https://item.jd.com/xxx.html`）
2. 按 F12 打开控制台，把 [standalone.js](standalone.js) 的全部代码粘贴进去回车
3. 首次运行会弹通知权限请求，点「允许」
4. 脚本每 20~30 分钟自动检测一次，有国补时弹浏览器通知 + 微信推送

**配置微信推送**：打开 [standalone.js](standalone.js) 第 16 行，把 SendKey 填进引号：

```js
const SERVERCHAN_SENDKEY = '你的SendKey';
```

> 独立版不自动刷新页面（刷新会清掉控制台注入的脚本），改用定时扫描 DOM。状态存在 `localStorage` 里，同一商品只在「无 → 有」变化时通知一次。

## 无痕模式

Chrome 扩展默认不在无痕模式运行，有两种解决方式：

- **方式一（推荐）**：用上面的「控制台独立版」，无痕模式下打开商品页直接粘贴脚本即可，无需任何额外配置
- **方式二**：在 `chrome://extensions` 找到本插件，点击「详情」，开启「允许在无痕模式下运行」，之后无痕窗口里的商品页也会自动注入脚本

## 工作原理

```
商品页 (content.js)                      插件后台 (background.js)
┌─────────────────────┐                ┌──────────────────────┐
│ 每 20~30 分钟随机刷新 │  检测到国补     │ 1. 弹 Chrome 系统通知  │
│ 等渲染后扫描           │ ──消息──→     │ 2. Server酱 推送到微信 │
│ .pay-right-text 元素  │                └──────────────────────┘
│ 正则匹配「领后减」金额 │
└─────────────────────┘
```

- 页面加载后等 10 秒让内容渲染完再检测，检测完随机等 20~30 分钟后自动刷新，循环往复（每次刷新间隔都不同，避开固定频率）
- 页面显示「又好又便宜」时静默等待，显示「领后减¥xxx 立即领取」时触发通知
- 通知里带商品标题（自动截取页面标题）和减免金额
- 每个商品独立去重（按商品 ID 存储状态）

## 常见问题

**插件装完没反应？**
装完插件（或重新加载插件）后，必须刷新商品页。内容脚本只对刷新后打开的页面生效。

**怎么确认插件在正常工作？**
在商品页按 F12 打开控制台，过滤输入 `国补`，正常应每 20~30 分钟输出一条检测日志：

```
[国补监控] 检测中... 找到 1 个 .pay-right-text 元素
```

**电脑弹窗不出现？**
检查 macOS 系统设置 → 通知 → Chrome，确认允许通知且未开启专注模式。

**微信收不到推送？**
先用浏览器直接访问 `https://sctapi.ftqq.com/你的SendKey.send?title=测试`，微信能收到说明配置没问题；再检查 `chrome://extensions` 里插件卡片的 service worker 控制台有没有「微信推送失败」日志（可能是当日 5 条额度用完）。

**页面为什么每 20~30 分钟随机刷新一次？**
国补状态由页面动态渲染，刷新才能拿到最新值。刷新发生在检测之后，如果你正盯着页面看，可能会感觉闪一下，属于正常现象。

**刷新页面会重复通知吗？**
不会。检测状态存在 chrome.storage 里，跨刷新、跨标签页生效，同一商品只在「无 → 有」变化时通知一次。

## 注意事项

- 监控期间浏览器和商品页标签需保持打开，页面关了监控就停了
- 插件只读取页面元素，不调用任何京东接口，不会触发风控
- 控制台独立版（standalone.js）在页面刷新后会丢失，需重新粘贴；如需刷新后自动续跑，请用扩展版或 Tampermonkey
